# Modelo Sociocognitivo de Análisis Crítico del Discurso - Teun A. van Dijk

## 📚 Referencia Teórica

Van Dijk, T. A. (2009). *Discurso y poder*. Barcelona: Gedisa.

Van Dijk, T. A. (2016). Análisis Crítico del Discurso. *Revista Austral de Ciencias Sociales*, 30, 203-222.

## 🎯 Definición del ACD según Van Dijk

> "El análisis crítico del discurso es una forma de investigación analítica del discurso que estudia principalmente el modo en que el abuso de poder, la dominación y la desigualdad son practicados, reproducidos y resistidos por los textos y el habla en el contexto social y político." (Van Dijk, 2009, p. 149)

## 🔺 Estructura Triangular del Modelo

```
        DISCURSO
         /    \
        /      \
   COGNICIÓN  SOCIEDAD
        \      /
         \    /
        CONTEXTO
```

El modelo de Van Dijk integra tres dimensiones fundamentales:

1. **Estructuras del Discurso** (nivel textual/lingüístico)
2. **Cognición** (nivel mental/representacional)
3. **Sociedad** (nivel social/estructural)

Estas tres dimensiones están mediadas por el **CONTEXTO**, representado como modelos mentales de la situación comunicativa.

## 1️⃣ ESTRUCTURAS DEL DISCURSO

### A. Macroestructura Semántica

**Definición**: Temas globales o tópicos que organizan el significado general del discurso.

**Cómo identificarla**:
- Preguntarse: "¿De qué trata globalmente este discurso?"
- Identificar proposiciones temáticas principales
- Observar qué se dice (y qué NO se dice - control de agenda)

**Ejemplo**:
```
Discurso sobre inmigración:
Macroestructura: "Control de fronteras para seguridad nacional"

Tópicos presentes:
- Inmigración irregular como amenaza
- Necesidad de políticas restrictivas
- Protección de ciudadanos nacionales

Tópicos ausentes (omisiones estratégicas):
- Causas de migración forzada
- Contribución económica de migrantes
- Historias personales de migrantes
```

### B. Superestructura

**Definición**: Esquemas formales que organizan el texto según género discursivo.

**Tipos de esquemas**:
- **Narrativo**: orientación → complicación → resolución → coda
- **Argumentativo**: tesis → argumentos → conclusión
- **Noticia**: titular → lead → cuerpo → cierre

**Ejemplo esquema noticioso**:
```
Titular: "Gobierno anuncia medidas contra inmigración ilegal"
Lead: Quién, qué, cuándo, dónde (énfasis en acciones gubernamentales)
Cuerpo: Detalles de medidas (perspectiva oficial dominante)
Cierre: Consecuencias esperadas (desde visión gubernamental)
```

### C. Microestructura Semántica

**Definición**: Relaciones semánticas entre proposiciones a nivel local.

**Elementos clave**:

1. **Implicaciones**: Lo que se sugiere sin decir explícitamente
   ```
   Explícito: "Muchos inmigrantes irregulares cruzan la frontera"
   Implícito: Los inmigrantes son ilegales, hay muchos, es problema
   ```

2. **Presuposiciones**: Lo que se da por sentado como verdad
   ```
   "El gobierno debe detener el flujo migratorio masivo"
   Presuposición: Ya existe un flujo masivo (puede no ser cierto)
   ```

3. **Coherencia local**: Conexiones entre proposiciones
   ```
   Coherencia causal: "Hay desempleo. Por eso limitar inmigración"
   (Establece causalidad que puede ser ideológica, no factual)
   ```

4. **Nivel de descripción**: Detalle vs generalización
   ```
   Sobre endogrupo (nosotros): Detalles específicos, individualizados
   Sobre exogrupo (ellos): Generalizaciones, categorías amplias

   Ejemplo:
   "Juan Pérez, padre de familia, perdió su empleo" (detalle)
   vs
   "Los inmigrantes compiten por trabajo" (generalización)
   ```

### D. Léxico

**Definición**: Elección de palabras que revelan ideología.

**Categorías**:

1. **Eufemismos**: Suavizar realidades negativas propias
   ```
   "Flexibilización laboral" en vez de "Precarización"
   "Daños colaterales" en vez de "Muertes civiles"
   ```

2. **Hipérboles**: Exagerar aspectos negativos del otro
   ```
   "Invasión migratoria" (en vez de "flujo migratorio")
   "Hordas" (deshumanización)
   ```

3. **Metáforas**: Marcos conceptuales ideológicos
   ```
   Metáfora bélica: "defender fronteras", "invasión"
   Metáfora acuática: "ola migratoria", "avalancha"
   ```

### E. Sintaxis

**Elementos ideológicos**:

1. **Voz activa vs pasiva**:
   ```
   Activa (atribuye agencia): "Policía disparó a manifestante"
   Pasiva (oculta agente): "Manifestante fue herido"
   ```

2. **Nominalización** (convertir verbos en nombres):
   ```
   "La represión de manifestantes" (oculta quién reprime)
   En vez de: "Policía reprimió manifestantes"
   ```

3. **Transitividad**: Quién hace qué a quién
   ```
   "Migrantes causan problemas" (agentes activos de negatividad)
   vs
   "Migrantes enfrentan discriminación" (pacientes de acciones ajenas)
   ```

## 2️⃣ COGNICIÓN

### A. Modelos Mentales

**Definición**: Representaciones cognitivas de experiencias o eventos específicos en memoria episódica.

**Componentes**:
- Participantes (quiénes)
- Acciones (qué hacen)
- Setting (dónde, cuándo)
- Evaluaciones subjetivas

**Función**: Median entre discurso y cognición social.

### B. Conocimiento

**Definición**: Creencias socialmente compartidas consideradas verdaderas por una comunidad.

**Características**:
- Compartido por grupo (común ground)
- Criterio de verdad consensuado
- Base para comunicación efectiva

### C. Actitudes

**Definición**: Evaluaciones socialmente compartidas sobre temas específicos.

**Estructura**:
- Creencias evaluativas organizadas
- Sobre objetos sociales (inmigración, política, etc.)
- Compartidas por grupos

### D. Ideologías

**Definición**: Sistemas fundamentales de creencias compartidas por grupos sociales que organizan actitudes específicas.

**Estructura de ideología grupal**:
1. Identidad (quiénes somos)
2. Actividades (qué hacemos)
3. Objetivos (qué queremos)
4. Normas y valores (qué es bueno/malo para nosotros)
5. Posición social (nuestra relación con otros grupos)
6. Recursos (qué tenemos/nos falta)

**Función ideológica del discurso**:
- Reproducir ideologías grupales
- Legitimar posición social
- Naturalizar relaciones de poder

## 3️⃣ CONTEXTO

### Modelo de Contexto

**Definición**: Representación mental subjetiva de la situación comunicativa.

**Componentes**:

1. **Setting**:
   - Tiempo
   - Lugar
   - Circunstancias

2. **Participantes**:
   - Hablante/Escritor
   - Audiencia
   - Roles sociales
   - Relaciones (poder, solidaridad)
   - Conocimiento compartido

3. **Acciones**:
   - Acto comunicativo en curso
   - Objetivos
   - Efectos deseados

**Función**: Explica por qué el mismo grupo puede hablar diferente según contexto.

Ejemplo:
```
Político hablando sobre inmigración:

Contexto A (Mitin partidario):
- Audiencia: Simpatizantes
- Rol: Líder de opinión
- Discurso: Radical, polarizante

Contexto B (Parlamento):
- Audiencia: Múltiples partidos + público general
- Rol: Representante institucional
- Discurso: Moderado, técnico
```

## 4️⃣ EL CUADRADO IDEOLÓGICO

### Estrategia Fundamental del Discurso Ideológico

Van Dijk (2009, p. 152) identifica el "cuadrado ideológico" como estructura básica:

```
Sobre NOSOTROS:                 Sobre ELLOS:
✅ Enfatizar lo POSITIVO         ⚠️ Enfatizar lo NEGATIVO
⬇️ Des-enfatizar lo NEGATIVO    ⬆️ Des-enfatizar lo POSITIVO
```

### Aplicación Práctica:

**Discurso nacionalista sobre inmigración**:

| Estrategia | Ejemplo |
|------------|---------|
| Nosotros+ | "Somos un país solidario, acogedor, con tradición humanitaria" |
| Nosotros- | "Lamentablemente, tenemos limitaciones de recursos" (minimizar) |
| Ellos- | "Inmigración irregular genera inseguridad, desempleo, problemas" |
| Ellos+ | [Omisión total de aspectos positivos de migrantes] |

## 5️⃣ CATEGORÍAS DE ANÁLISIS (Checklist Práctico)

### ✅ Análisis de Tópicos

- [ ] ¿Qué temas se discuten? (macroestructura)
- [ ] ¿Qué temas se OMITEN? (control de agenda)
- [ ] ¿Cuánto espacio se dedica a cada tema? (relevancia)

### ✅ Análisis Semántico Local

- [ ] ¿Qué implica el texto sin decirlo explícitamente?
- [ ] ¿Qué presupone como verdad sin argumentar?
- [ ] ¿Qué nivel de detalle usa para describir a cada actor?
- [ ] ¿Cómo conecta proposiciones? (causalidad, contraste, etc.)

### ✅ Análisis Léxico

- [ ] ¿Qué palabras selecciona para cada concepto?
- [ ] ¿Usa eufemismos? (¿para ocultar qué?)
- [ ] ¿Usa hipérboles? (¿para exagerar qué?)
- [ ] ¿Qué metáforas emplea? (¿qué marco conceptual activan?)

### ✅ Análisis Sintáctico

- [ ] ¿Quién es sujeto activo de acciones positivas?
- [ ] ¿Quién es sujeto activo de acciones negativas?
- [ ] ¿Qué verbos se nominalizan? (¿para ocultar agencia?)
- [ ] ¿Cuándo usa voz pasiva? (¿qué agente oculta?)

### ✅ Análisis Retórico

- [ ] ¿Qué figuras retóricas emplea?
- [ ] ¿Qué estrategias de persuasión identifica?
- [ ] ¿Cómo apela a emociones?
- [ ] ¿Qué evidencia ofrece? (¿es suficiente?)

### ✅ Análisis del Cuadrado Ideológico

- [ ] ¿Qué aspectos positivos de NOSOTROS enfatiza?
- [ ] ¿Qué aspectos negativos de NOSOTROS minimiza/oculta?
- [ ] ¿Qué aspectos negativos de ELLOS enfatiza?
- [ ] ¿Qué aspectos positivos de ELLOS minimiza/oculta?

## 6️⃣ PROCEDIMIENTO DE ANÁLISIS PASO A PASO

### Paso 1: Definir Pregunta de Investigación

Ejemplo: "¿Cómo se construye discursivamente la representación de migrantes venezolanos en discursos presidenciales chilenos 2018-2024?"

### Paso 2: Seleccionar Corpus

- Definir criterios de selección
- Asegurar representatividad
- Saturación (cuando no emergen patrones nuevos)

### Paso 3: Análisis Textual

Para CADA texto del corpus:

1. Identificar macroestructura (tema global)
2. Analizar superestructura (esquema organizativo)
3. Examinar microestructura:
   - Implicaciones
   - Presuposiciones
   - Nivel de descripción
   - Coherencia local
4. Analizar léxico (palabras clave, metáforas, eufemismos)
5. Analizar sintaxis (agencia, voz, nominalización)
6. Identificar cuadrado ideológico

### Paso 4: Codificación

Crear códigos para categorías Van Dijk:

```
Ejemplo de códigos:

VD_TOPICO_SEGURIDAD: Fragmentos que tematiza inmigración como amenaza seguridad
VD_TOPICO_ECONOMIA: Fragmentos que tematizan impacto económico
VD_OMISION_CAUSAS: Ausencia de mención a causas de migración
VD_LEXICO_EUF_CONTROL: Eufemismos para restricción ("ordenamiento", "regulación")
VD_LEXICO_HIP_CANTIDAD: Hipérboles sobre cantidad ("avalancha", "masivo")
VD_SINTAXIS_PASIVA_OCULTA: Voz pasiva ocultando agente gubernamental
VD_CUADRADO_NOSOTROS_POS: Énfasis aspectos positivos país receptor
VD_CUADRADO_ELLOS_NEG: Énfasis aspectos negativos migrantes
```

### Paso 5: Interpretación Cognitiva

- ¿Qué modelos mentales activa este discurso?
- ¿Qué conocimientos presupone como compartidos?
- ¿Qué actitudes reproduce/construye?
- ¿Qué ideología subyace?

### Paso 6: Explicación Social

- ¿Cómo este discurso reproduce relaciones de poder?
- ¿Qué intereses grupales legitima?
- ¿Qué consecuencias sociales tiene?
- ¿Quién se beneficia de estas representaciones?

## 7️⃣ EJEMPLO DE ANÁLISIS COMPLETO

### Fragmento a analizar:

> "Chile es un país solidario que históricamente ha acogido a quienes buscan mejores oportunidades. Sin embargo, no podemos permitir que la inmigración irregular ponga en riesgo nuestra seguridad y la estabilidad de nuestras familias. Es necesario avanzar en un ordenamiento migratorio que proteja a todos los chilenos." (Discurso presidencial ficticio)

### Análisis Van Dijk:

**MACROESTRUCTURA:**
- Tema: Control migratorio como protección nacional

**MICROESTRUCTURA:**

*Implicaciones*:
- "Inmigración irregular" implica ilegalidad, problema
- "Pone en riesgo" implica amenaza actual
- "Proteger chilenos" implica que están desprotegidos por migrantes

*Presuposiciones*:
- Presupone que inmigración irregular amenaza seguridad (no argumentado)
- Presupone división binaria chilenos vs migrantes

*Nivel de descripción*:
- Alto detalle positivo sobre "Chile" (solidario, acogedor)
- Generalización sobre "inmigración irregular" (sin rostro, sin causas)

**LÉXICO:**

*Eufemismos*:
- "Ordenamiento migratorio" = restricción/control (suaviza medida represiva)

*Metáforas*:
- Metáfora de riesgo/amenaza ("poner en riesgo", "proteger")

**SINTAXIS:**

*Agencia*:
- Sujeto activo positivo: "Chile ha acogido" (nosotros como actores generosos)
- Sujeto activo negativo: "Inmigración pone en riesgo" (ellos como amenaza)

**CUADRADO IDEOLÓGICO:**

| Nosotros+ | "País solidario", "históricamente acogedor" |
| Nosotros- | [Minimizado] "No podemos permitir" (límites presentados como inevitables, no como decisión restrictiva) |
| Ellos- | "Inmigración irregular", "riesgo", "amenaza a seguridad y estabilidad" |
| Ellos+ | [Omisión total] No menciona aportes, causas humanitarias de migración |

**INTERPRETACIÓN COGNITIVA:**

*Modelo mental activado*:
- Escenario de amenaza externa que requiere defensa nacional

*Actitud reproducida*:
- Inmigración como problema de seguridad (no humanitario, no económico positivo)

*Ideología subyacente*:
- Nacionalismo excluyente
- Priorización endogrupo sobre exogrupo

**EXPLICACIÓN SOCIAL:**

*Relaciones de poder*:
- Legitima políticas restrictivas
- Deshumaniza migrantes (sin rostro, sin causas)
- Construye consenso en torno a control

*Efectos sociales*:
- Naturaliza discriminación
- Justifica medidas represivas
- Reproduce desigualdad estructural
